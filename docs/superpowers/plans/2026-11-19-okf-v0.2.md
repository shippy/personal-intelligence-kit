# OKF v0.2 Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the generated `output/` bundle from OKF v0.1 frontmatter to the applicable v0.2 subset (`generated`, structured `sources`, `stale_after`, optional `verified`; no `status`).

**Architecture:** All emission goes through `_lib/okf.py::write_concept`. The helper's frontmatter renderer and reader become recursive over a flow-YAML subset (still no PyYAML); `write_concept` computes the v0.2 fields. Each of the six writers changes only its `write_concept` call(s), plus a model-name attribute where an LLM path needs to report its model.

**Tech Stack:** Python 3.11+ stdlib (`datetime`), `uv`, `pytest`. Tests run inside the `pki-okf-v02` sbx sandbox (repo bind-mounted at the same path).

**Spec:** `docs/superpowers/specs/2026-11-19-okf-v0.2-design.md`

## Global Constraints

- `_lib/okf.py` stays dependency-free: `uv run --no-project --with pytest pytest _lib/test_okf.py` (from `template/.claude/skills`) must pass with no `--with pyyaml`.
- `generated` = `{by: <actor>, at: <ISO 8601 datetime>}`; `timestamp` kept as `YYYY-MM-DD`.
- `sources` = `[{resource: "source:<feed>"}, …]`.
- `stale_after` = `generated.at` + horizon; `DEFAULT_STALE_DAYS = {"alert": 7, "report": 14, "reflection": 30}`.
- `status` is never emitted.
- Actor: deterministic → `process:<skill>`; LLM path actually ran → `<skill>/<model>`.
- Writers pass no `verified`.
- Do not touch `logs/activity/`, `logs/sync.jsonl`, or any `append_activity` call.
- `uv` only. Commits as the bot, no attribution lines.

## Review Focus

1. Scalars containing `,` `:` `{` `}` `[` `]` or `"` inside nested mappings/lists (e.g. a feed name or actor with a comma) must round-trip through render → read unchanged. Test: `test_nested_roundtrip_with_special_chars` (Task 1).
2. A stale caller still passing `status=` or `sources=` via `**extra` would silently emit invalid v0.2 frontmatter. Expected: `TypeError`. Test: `test_write_concept_rejects_legacy_fields` (Task 2).
3. Empty or whitespace `generated_by` produces a document with no provenance. Expected: `ValueError`. Test: `test_write_concept_requires_actor` (Task 2).
4. Types outside the default table (e.g. `"t"` used by vault-config tests) still need a horizon. Expected: fallback 14 days. Test: `test_stale_after_fallback_for_unknown_type` (Task 2).
5. Duplicate or empty feed lists (`[]` from intention-reality with no feeds) must not render `sources: []` or repeated entries. Expected: duplicates dropped in order; empty → key omitted. Test: `test_source_feeds_dedupe_and_empty` (Task 2).
